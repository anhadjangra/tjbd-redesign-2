# TJBD Portfolio City

A 3D concept for the Tarun Jangra Building Designers website (tjbuildingdesigners.com.au). All 27 projects are drawn as one city: each is a lot sized from its published site area, with a building that grows with its floor area and is wrapped in that project's photos. Lots are grouped into districts coloured like a town-planning zoning map, and scrolling flies from district to district.

It is a single static page with no build step: `index.html` plus `img/` and `media/`. three.js 0.160.0 loads from jsDelivr. To run it locally, serve the folder with any static server, for example `python3 -m http.server`.
